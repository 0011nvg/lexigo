# LEXIGO — Learn. Play. Remember.

Интерактивная платформа для изучения английской лексики по Spotlight 2, 3 и 4.

## Разработка

Исходный словарь из Word-документа сохраняется без изменений: написание, перевод, порядок и повторы. Игровые задания и иллюстрации разрабатываются отдельно.

## Публикация

Сайт размещается через GitHub Pages. Для публикации приложения в корне репозитория нужны `index.html` и `data.js` из архива LEXIGO v2. После добавления файлов откройте Settings → Pages и выберите GitHub Actions в разделе Build and deployment.

## Качество

Перед релизом: проверка методики, языка, логики игр, доступности, мобильного интерфейса и тестов.
