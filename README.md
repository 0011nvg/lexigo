# LEXI — Learn. Play. Remember.

Интерактивная платформа для изучения английской лексики по Spotlight 2–9.

## Разработка

Исходный словарь из Word-документа сохраняется без изменений: написание, перевод, порядок и повторы. Игровые задания и иллюстрации разрабатываются отдельно.

## Публикация

Сайт размещается через GitHub Pages. Для публикации приложения в корне репозитория нужны `index.html` и `data.js` из архива LEXI v2. После добавления файлов откройте Settings → Pages и выберите GitHub Actions в разделе Build and deployment.

## Качество

Перед релизом: проверка методики, языка, логики игр, доступности, мобильного интерфейса и тестов.

## Методические улучшения

- «Тренировка дня»: короткий маршрут из выбранных слов с приоритетом повторения и ошибок.
- Раздельная фиксация узнавания и самостоятельного написания.
- Интервалы повторения и фильтр «Повторить сегодня» (локально в браузере).
- Отсев неоднозначных пар с одинаковыми переводами в одной игре.
- Проверка продуктивного навыка при прохождении босса.

Проверены целостность базы и синтаксис JavaScript. Полноценное ручное тестирование на реальных мобильных устройствах и пилот с детьми ещё предстоят.

## Доработки интерфейса и игр (02.11.2026, вечер)

- **Выбор слов**: в уроке «Слова урока · выбрать» → галочки, «Выбрать все», «Снять выделение», счётчик «Выбрано N из M». Набор запоминается для каждого урока и модуля (на устройстве, отдельно для каждого аккаунта) и действует во всех играх, включая финальный тест и работу над ошибками.
- **Несколько игр подряд**: «▶ Пройти по порядку» (все игры трёх этапов «Знакомлюсь — Вспоминаю — Проверяю себя») или «☑ Выбрать игры» — отметить нужные и пройти подряд; после каждой игры — кнопка «Дальше».
- **Финальный тест** настраивается: какие типы заданий включить (Кристальная экспедиция не входит), по выбранным словам; работа над ошибками в конце сохранена.
- **ТОП-3** после игры: общий рейтинг на сервере (Supabase), место считает сервер, имя 2–20 символов; гости видят таблицу, записаться может только вошедший ученик.
- Звание вместо «Ур. 1 · 0 XP» в шапке; «Учебники» → «Уроки»; режимы «Игровой/Спокойный» и «Урок на доске» убраны, крупный шрифт — по умолчанию; новые цвета «Верно / неверно».
- **Проверочная работа A4**: поля 20 мм слева и справа, 20 заданий на странице, автоуменьшение шрифта для очень длинных слов; `print.css`, тест `tests/print-layout.mjs`.

## Ребрендинг: LEXI (02.11.2026)

Платформа называется **LEXI**, её герой — кот **Лекси**. Логотип: слово LEXI и лаймовая «кошачья точка» с ушками — как в «lexi.» (`polish.css`, `.brand-cat`; для печати — `.print-cat` в `print.css`). Иконки: `assets/lexi-icon.svg`, `lexi-icon-192/512.png`, `apple-touch-icon.png`; карточка для ссылок `assets/og-lexi.jpg`; `manifest.webmanifest`.

Адрес сайта и репозиторий по-прежнему `lexigo`; внутренние имена (`lexigo_*` в хранилище браузера, `LexigoCloud`, `LEXIGO_DATA`, `#lexigoPrint`) не переименованы намеренно, чтобы сохранить прогресс пользователей и стабильность.

## Личное пространство ученика (02.11.2026)

- **Логотип**: новый знак — силуэт головы кота с салатовыми глазами перед словом LEXI (шапка, подвал, вход, кабинет, печать, иконки сайта и картинка для ссылок). Анимированный котёнок Лекси не менялся.
- **Мой класс** (`lexigo_my_class_v1`): выбирается один раз на главной (кнопки 2–9), меняется только явно («Сменить класс» или «Сделать моим классом» на странице учебника). Открыть урок другого класса можно в любой момент — основной класс от этого не меняется.
- **Продолжить обучение** (`lexigo_last_activity_v1`): последний урок/модуль, последняя игра и завершена ли она. Незавершённая игра честно начинается заново; после завершённой — «Дальше: следующая игра» или «Повторить».
- **Мои модули** (`lexigo_fav_modules_v1`): ☆ у названия модуля на странице учебника, до 12 модулей из любых классов; быстрые ссылки и удаление «×» на главной.
- **Сложные слова** (`lexigo_hard_words_v1`): ☆ у слова в списке (и кнопка «Добавить ошибки в сложные» после игры). На главной — «Мои сложные слова · N слов · Повторить» отдельно по каждому модулю, слова разных классов и модулей не смешиваются. Слово уходит из списка само после 3 верных ответов подряд или по нажатию ★.
- **Набор слов для игр** (`lexigo_word_selection_v1`, формат `{ "класс:урок": { m: "all"|"chosen"|"hard", ids } }`, старый формат-массив читается): «Все слова / Выбранные / ★ Сложные» на странице урока. Набор действует во всех играх урока, пока его не поменяют; при переключении на «Все» свой выбор не теряется. Если слов мало — подсказка, каким играм нужно 2 или 3 слова.
- Всё это хранится **в этом браузере на этом устройстве** (у вошедшего ученика — отдельно для его аккаунта) и не синхронизируется между устройствами; так и написано на главной.
- Тесты: `tests/personal.mjs` (новый ученик, 10 слов в нескольких играх, мало слов, сложные слова после перезагрузки, избранные модули из двух классов, временный переход в 5 класс, возвращение, старый формат, iPhone; в CI ещё и WebKit).

## Точечные доработки (02.11.2026, вечер)

- **Знак LEXI v3**: та же голова кота, но с круглыми глазами с бликами и розовым носом (как у основного котёнка); моргает и кивает при наведении, при `prefers-reduced-motion` без анимации. Обновлены иконки и картинка для соцсетей.
- **Сразу к играм**: убран выбор «Пройти по порядку / Выбрать игры» — после набора слов сразу все игры; финальный тест по-прежнему открывает свои настройки.
- **Конструктор слов и аудиодиктант — только отдельные слова** (`isSingleWordEntry`, `isBuilderWord` в `practice-controller.js`): фразы определяются по структуре (`get up`, `How are you?`, `a/an`), а `don't`, `ice-cream`, `T-shirt`, `Mr.`, `Hello!` — отдельные слова. Фразы не удаляются и работают в других играх. Буквы в конструкторе строчные (заглавная не подсказывает первую букву). Если подходящих слов нет — сообщение и возврат к играм.
- **Учитель**: нет блока «Тренировать слова» и выбора времени; слова выбираются прямо в «Материалах к уроку».
- **Печать**: поля 20 мм сверху/снизу и 15 мм слева/справа, 20 заданий на листе ученика (для очень длинных фраз — более плотный шрифт). Отдельный лист **«Критерии оценивания для учителя»**: количество заданий, максимальный балл, правила по типам, частичный балл 0,5 (по желанию), перевод в отметку по шкале школы (по умолчанию 90/75/50 %, хранится в `lexigo_grade_scale_v1`), ключи.
- **«Верно / неверно»**: спокойные кнопки в палитре LEXI со значками ✓/✕; при верном ответе — короткая плашка, реплика Лекси и автопереход; при ошибке — короткое пояснение с правильной парой.
- **Лекси говорит по-английски**: короткие фразы с русской подсказкой на главной (приветствие по времени суток, «Welcome back!», реакции на касание), без повторов подряд; 🔊 только по нажатию. В играх — английские реплики к началу, верному ответу и итогу.
- Тест: `tests/rules.mjs`.

**Обновления без кэша.** Ссылки на CSS и JS во всех страницах помечены версией (`?v=20261102c`). При каждой новой выкладке меняйте эту метку — тогда браузеры сразу загрузят новые файлы, а не старые из кэша (GitHub Pages разрешает кэш до 10 минут). `config.js` не помечается.

## Уроки от учителя — полноценная часть LEXI (02.11.2026, v3)

- **Ученик.** Назначенный урок — первым на главной: крупная карточка «Твой урок от учителя» (название, учитель, сколько слов, прогресс игр и слов, статус «Не начат / В процессе / Завершён», кнопка «Открыть урок / Продолжить / Повторить»). Несколько уроков — самый актуальный первым, остальные ниже; завершённые остаются для повторения. Нет уроков — блока нет. В кабинете — раздел «Уроки от учителя» сразу после приветствия.
- **Страница урока** `index.html#/my/a-<задание>`: слова с переводом и озвучкой, все игры LEXI, которые подходят к словам (★ — игры, выбранные учителем; они определяют «Завершён»). Игры открываются на обычном игровом экране (`#/my/…/play/<игра>`), «← К режимам» и «Вернуться к уроку» ведут обратно на страницу. Прогресс — в аккаунте.
- **Учитель.** «Мои уроки» — карточки (название, слова, дата, кому назначен и сколько выполнили; «Открыть», «▶ Играть», «Редактировать», «Назначить»); форма нового урока — по кнопке «＋ Новый урок». Страница своего урока `#/my/t-<урок>` — та же, что у ученика, в режиме тренировки: можно пройти любую подходящую игру; ничего не уходит в статистику класса.
- **Единый движок.** Учебник, урок ученика и урок учителя запускают одну и ту же функцию `start()`; различаются только слова и «метка» результата. Список игр страницы урока берётся из того же блока игр, что на уроке учебника, — новая игра появится и в уроках учителя сама, если подходит к словам (`LexigoCloud.modeFit`).
- **«Конструктор слов»** (`word-builder.js`): плитки = символы правильного написания (каждая буква столько раз, сколько в слове; заглавные London, Monday, UK сохраняются; T‑shirt и baker’s с типографскими знаками приводятся к обычным); набор проверяется перед показом, неподходящее слово (фраза, 1 буква, больше 14 букв) пропускается.
- Новые файлы: `word-builder.js`, `my-lessons.js`, `lessons.css`; тесты `tests/word-builder.mjs`, `tests/builder-play.mjs`, `tests/e2e/lesson-pages.mjs`. Метка версии файлов — `?v=20261102h`. База данных не менялась.

## «Кристальная экспедиция» v2 — настоящая игра «три в ряд» (02.11.2026)

- **Правила** (`crystal-engine.js`, без DOM, детерминированный): меняй соседние кристаллы (перетаскиванием, двумя касаниями или с клавиатуры); неверный ход возвращает кристаллы и не тратит ход; ряды по горизонтали и вертикали, каскады, автоматическое перемешивание без потери хода, если ходов нет.
- **Особые кристаллы**: 4 в ряд — «линия» (строка или столбец), уголок/«Т» из 5 — «бомба» 3×3, 5 в ряд — «призма» (все кристаллы одного цвета; меняется с любым соседом); сочетания: линия+линия — крест, бомба+бомба — 5×5, призма+особый — все кристаллы цвета становятся особыми. Лёд в клетках.
- **5 уровней**: «Первые кристаллы» (7×7, очки) → «Мастер комбинаций» (линии и призмы) → «Кристальный взрыв» (бомбы) → «Цепная реакция» (лёд, сбор цвета, цепочки) → «Легенда кристаллов» (несколько целей, толстый лёд). Ограниченные ходы, 1–3 звезды, оставшиеся ходы после победы превращаются в бонус. Сложность проверена симуляцией двух «игроков» (`tests/crystal-engine.mjs`).
- **Слова**: собранные кристаллы заряжают «Энергию Лекси»; между ходами — карточка со словом урока (перевод, верно/неверно, исправь букву, конструктор, написание — по уровню). Не больше одной карточки за ход. Верно — +1 ход, +150 очков и особый кристалл; ошибка без штрафа — слово вернётся в простом задании. Ответы сохраняются как в остальных играх (прогресс слов, XP, задания учителя).
- **«Экспедиция дня»**: в один день у всех игроков одинаковое поле уровня — честное соревнование.
- **Рекорды и рейтинг**: на устройстве (у вошедшего — отдельно для аккаунта) и на сервере (`crystal_runs`, `crystal_names`, функции `crystal_start / crystal_finish / crystal_my / crystal_top / crystal_set_name` в `supabase/schema.sql`). Сервер сам считает звёзды и очки рейтинга (звёзды + точность ответов + сэкономленные ходы + очки уровня с пределом), проверяет правдоподобие (ходы сходятся с ответами, предел очков, время на ход, цели), не принимает одну партию дважды. В рейтинге — только ник или «Исследователь XXXX». Тренировка учителя в рейтинг не попадает.
- **Экран**: карта уровней, ходы, очки со звёздами, цели, «Энергия Лекси», подсказка через 7 с, пауза, экран итогов («Следующий уровень», «Попробовать ещё раз», «Карта уровней», «К выбору игр»). Звук и «Спокойная анимация» отключаются. Кристаллы разных цветов — разной формы.
- Файлы: `crystal-engine.js`, `crystal-quest.js`, `crystal.css`; тесты `tests/crystal-engine.mjs`, `tests/crystal-play.mjs`, `tests/e2e/crystal-rating.mjs`. Старые `tests/crystal-policy.mjs` и `tests/crystal-webkit.mjs` заменены.
