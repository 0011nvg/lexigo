# LEXIGO — Learn. Play. Remember.

Интерактивная платформа для изучения английской лексики по Spotlight 2–9.

## Разработка

Исходный словарь из Word-документа сохраняется без изменений: написание, перевод, порядок и повторы. Игровые задания и иллюстрации разрабатываются отдельно.

## Публикация

Сайт размещается через GitHub Pages. Для публикации приложения в корне репозитория нужны `index.html` и `data.js` из архива LEXIGO v2. После добавления файлов откройте Settings → Pages и выберите GitHub Actions в разделе Build and deployment.

## Качество

Перед релизом: проверка методики, языка, логики игр, доступности, мобильного интерфейса и тестов.

## Контроль словаря (21.10.2026)

Повторно сверено с предоставленным Word-файлом: **1035 записей**, Spotlight 2 — **236**, Spotlight 3 — **423**, Spotlight 4 — **376**. Английские слова, переводы, повторы и последовательность записей совпадают с исходным документом. `data.js` и `data.json` согласованы между собой, идентификаторы всех записей уникальны.

**Важно о структуре источника:** в исходном файле есть нестандартный порядок уроков в Spotlight 3 (Part 2), переход `Module 5 → Module 8 → Module 6` в Spotlight 4 (Part 2), одиночные записи до заголовков уроков и раздел `spaces`. Платформа **не исправляет эти места самостоятельно**, чтобы не исказить оригинал. Уточнение привязки этих записей к модулям требует редакторского решения.

## Методические улучшения

- «Тренировка дня»: короткий маршрут из выбранных слов с приоритетом повторения и ошибок.
- Раздельная фиксация узнавания и самостоятельного написания.
- Интервалы повторения и фильтр «Повторить сегодня» (локально в браузере).
- Отсев неоднозначных пар с одинаковыми переводами в одной игре.
- Проверка продуктивного навыка при прохождении босса.

Проверены целостность базы и синтаксис JavaScript. Полноценное ручное тестирование на реальных мобильных устройствах и пилот с детьми ещё предстоят.
