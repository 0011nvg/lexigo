# LEXI · ручная проверка push-уведомлений (iPhone и Android)

Автотесты проверяют интерфейс, сервер (SQL) и подпись/шифрование сообщений, но не доставку на настоящий телефон.
Эту проверку нужно сделать один раз руками. Понадобятся: iPhone с iOS 16.4 или новее (или Android-телефон с Chrome),
тестовый аккаунт ученика и аккаунт учителя, в котором есть класс с этим учеником.

## iPhone (ученик)
1. Откройте https://0011nvg.github.io/lexigo/ в **Safari**. «Поделиться» → «На экран „Домой“» → «Добавить».
2. Откройте **LEXI со значка на экране «Домой»** (не из Safari) и войдите как ученик.
3. Кабинет (значок уровня справа вверху) → «Уведомления» → «🔔 Включить уведомления» → в системном окне «Разрешить».
   Ожидается: «● Включены на этом устройстве».
4. «Проверить уведомление» → сверните приложение. Через несколько секунд должно прийти «🐱 Лекси на связи!».
5. Нажмите на уведомление — откроется кабинет LEXI.
6. **Новый урок**: учитель на другом устройстве назначает этому классу урок (Кабинет → Задания → ＋ Задание).
   Ученику приходит «🐱 Лекси: новый урок!», нажатие открывает именно этот урок. Приложение при этом может быть закрыто.
7. **Ежедневное напоминание**: в «Уведомлениях» выберите время на 30 минут позже текущего, ничего не проходите
   до этого времени и закройте приложение. Должно прийти одно напоминание (повторно за вечер — нет).
   Если до этого времени открыть сундук дня (все 3 миссии) или заниматься в момент напоминания — оно не придёт.
8. «Выключить на этом устройстве» → «Проверить уведомление» больше ничего не присылает.
9. Выход из аккаунта (Кабинет → «Выйти») — уведомления этого аккаунта на телефон больше не приходят.

## Android (Chrome)
Те же шаги 3–9. Устанавливать на главный экран не обязательно (можно и во вкладке Chrome), но с установкой надёжнее.

## Если не приходит
* Настройки iPhone → Уведомления → LEXI: «Допуск уведомлений» включён, режим «Фокус» не скрывает LEXI.
* В «Уведомлениях» кабинета статус «Включены на этом устройстве». Если нет — нажмите «Включить» ещё раз.
* Supabase → Edge Functions → push-worker → Logs: ответы push-сервиса (410 — подписка устарела и удалена).
* Supabase → SQL: `select kind, title, created_at, sent_at, delivered from public.push_outbox order by id desc limit 20;`
