# LEXI: аудит PWA и последующие проверки

## Состав и производительность

Сайт — статические HTML, CSS и JavaScript; обязательной сборки нет. Уроки используют маршруты с `#`, кабинеты и вход — отдельные HTML-страницы. При статическом подсчёте прямых ссылок в `index.html` обнаружено 52 локальные ссылки общим размером примерно 1,39 МБ до сжатия, без учёта самого HTML, динамической загрузки, изображений и кэша браузера. Это не сетевой замер и не оценка скорости загрузки. Крупные словари классов загружаются на главной, например файлы для 8 и 9 классов занимают около 178 и 161 КБ соответственно; будущую отложенную загрузку стоит проектировать отдельно и проверять глубокие ссылки и игры, прежде чем применять.

Шрифты поставляются локально, библиотека Supabase также включена в репозиторий. Для облачных функций необходимы GitHub Pages, сеть и Supabase; доступность из российских сетей в ходе этой работы не измерялась. Не переносите реальные данные на другой сервис или в другой регион без отдельного решения.

## Звук и системные ограничения

Проект использует `speechSynthesis` и голос устройства. Режимы предусматривают ручную кнопку повторного воспроизведения; наличие API само по себе не гарантирует доступность английского голоса или успешное автоматическое воспроизведение на iOS. Проверка звука, клавиатуры, блокировки экрана, звонка и возвращения в приложение на реальных устройствах остаётся необходимой. Существующий код PWA не обходит ограничения звука операционной системы.

## Проверка выпуска

Настоящие показатели первого и повторного запуска, Lighthouse, использование памяти, плавность на бюджетном Android и расход трафика следует измерять на тестовом развёртывании и реальных устройствах. Просмотреть все игры, включая завершение и повторное открытие, а также пользовательские уроки, печать, клавиатуру и входы в кабинеты. Гостевой браузерный тест или подмена API не подтверждает работу Supabase Auth, синхронизацию или восстановление данных. Результаты таких проверок фиксировать отдельно от имитаций.

## Дальнейшее развитие

Для безопасного автономного запуска и надёжных обновлений нужна согласованная версия приложения с неизменяемыми идентификаторами файлов и отдельно протестированным порядком публикации HTML и ресурсов. Очередь попыток и межустройственная синхронизация относятся к отдельной серверной работе; локальный кэш PWA не является резервной копией. Архитектуру можно в дальнейшем оценить для Capacitor после проверки ссылок, авторизации, аудио и правил магазинов; зависимость Capacitor сейчас не добавлена.
