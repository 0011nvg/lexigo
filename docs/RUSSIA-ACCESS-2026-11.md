# LEXI в России без VPN: аудит доступности (3 ноября 2026)

## Важно: что проверено, а что нет

Проверки шли из облака **за пределами России**. Реальную доступность из российских сетей (домашний интернет, мобильные операторы) **проверить не удалось**, поэтому здесь нет утверждений «работает в России» или «не работает». Ниже — что и как устроено, где риски по открытым данным и как проверить на месте (раздел 5).

## 1. От чего зависит сайт

Вывод: **игры и словари (без входа) зависят только от GitHub Pages, а всё, что связано с аккаунтами, — от `supabase.co` за Cloudflare.** Второе — главный риск.

## 2. Что уже сделано (безопасно, без смены инфраструктуры)

* Запросы к серверу аккаунтов прерываются через 15 с, а не висят бесконечно; сайт продолжает работать в гостевом режиме и пишет понятно: «Сервер аккаунтов сейчас не отвечает. Игры работают и без входа…» (`cloud-core.js`).
* Сбой облака не ломает игры: всё, кроме облачных функций, работает в гостевом режиме (проверено тестами с полностью недоступным облаком).
* Страница **`check.html`** («Проверка связи LEXI», не связана с меню): проверяет из сети пользователя главную страницу, большие файлы словарей (> 16 КБ — ловит ограничение «первых 16 КБ»), шрифт, картинки, модуль аккаунтов, сервер аккаунтов (вход и данные) и голоса для озвучки. Кнопка «Скопировать отчёт».
* Адрес сервера аккаунтов задаётся одной строкой в `config.js` — переезд или прокси не требуют правок кода.

## 3. Варианты решения (требуют вашего согласования)

### Вариант 1 (рекомендую): всё в России, один сервер — «режим Б» из `CLOUD-SETUP.md`

* VPS в российском дата-центре (например, Timeweb Cloud: 2 ядра / 4 ГБ / 40 ГБ NVMe — по данным самого Timeweb, от ≈1 460 ₽/мес).
* На нём: **Supabase self-hosted** (Docker, тот же `supabase/schema.sql`) и сами файлы сайта (nginx/Caddy с бесплатным сертификатом Let's Encrypt).
* Свой домен `.ru` (≈200–900 ₽/год; с апреля 2026 регистрация `.ru/.рф` — с подтверждением через Госуслуги).
* Письма: SMTP Яндекс 360 или Mail.ru — ссылки в письмах ведут на ваш домен.
* Обновление: GitHub остаётся хранилищем кода; GitHub Actions после каждого коммита копирует сайт на сервер. GitHub Pages можно оставить как запасное зеркало.
* Перенос аккаунтов: выгрузка `auth` и `public` из облачного проекта (pg_dump) и загрузка на новый сервер — пароли переносятся, пользователям ничего делать не нужно.

**Плюсы:** не зависит от Cloudflare, Fastly и `supabase.co`; закрывает требование 152‑ФЗ о хранении персональных данных в РФ (ч. 5 ст. 18), которое всё равно нужно для реальных учеников; одна понятная точка.
**Минусы и риски:** сервер нужно сопровождать (обновления, резервные копии — настраиваются один раз скриптами); один сервер — одна точка отказа (резервные копии в отдельное хранилище); переезд займёт рабочий день плюс проверка; ≈1,5–2,5 тыс. ₽ в месяц.

### Вариант 2: сайт в России, база пока в Supabase Cloud через свой домен

* Файлы сайта — Yandex Object Storage (или Selectel/Timeweb S3) со своим доменом и HTTPS, копеечная стоимость для сайта в 5 МБ.
* К Supabase — через свой домен-прокси. Без российского сервера прокси сам окажется за границей и может попасть под те же ограничения; кастомный домен Supabase — платный тариф.

**Плюсы:** быстрее. **Минусы:** не решает надёжно проблему аккаунтов и 152‑ФЗ; по сути промежуточный шаг.

### Вариант 3: ничего не переносить

Игры могут работать, если GitHub Pages открывается; аккаунты, вероятно, будут нестабильны. Подходит только для пилота с VPN.

## 4. Рекомендация

**Вариант 1.** Он единственный убирает зависимость от обоих рискованных узлов (Fastly/GitHub и Cloudflare/supabase.co) и одновременно закрывает юридическое требование к данным учеников. Сначала — проверка по разделу 5 из 2–3 разных сетей, чтобы подтвердить проблему фактами.

## 5. Как проверить из России (5 минут)

1. Без VPN откройте на телефоне и на компьютере (разные сети: домашний Wi‑Fi, мобильный интернет МТС/Билайн/МегаФон/Tele2):
   `https://0011nvg.github.io/lexigo/check.html` → дождитесь результата → «Скопировать отчёт».
2. Пройдите сценарий: главная → учебник → модуль → любая игра → аудиодиктант → регистрация → письмо → ссылка из письма → вход → прогресс на втором устройстве → кабинет учителя → урок учителя.
3. Пришлите отчёты: по ним видно, что именно не грузится (файлы сайта, сервер аккаунтов, ссылка из письма) и где.

Источники: OONI/«Вёрстка» о сбоях GitHub в РФ (май 2026); Cloudflare и СМИ об ограничении «16 КБ» (с июня 2025); блог Supabase «Navigating Regional Network Blocks» (март 2026); тарифы Timeweb Cloud.
